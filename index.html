About

Defensive security, practised hands-on

I'm a final-year BS Cyber Security student at Mehran University of Engineering & Technology, Jamshoro, working in security operations. My SOC experience comes from real monitoring work: reviewing daily security events in Wazuh, investigating brute-force and authentication anomalies across Linux and Windows endpoints, writing detection rules for gaps in coverage, and mapping what I find to MITRE ATT&CK.

The defensive work is sharper because of the offensive side. A red team internship covering web application VAPT, independent bug hunting with responsible disclosure, and 150+ PortSwigger labs mean I've run most of the attacks I'm asked to detect. A home lab running Splunk, Wazuh, ELK, pfSense and Suricata is where I test whether a rule actually fires.

My research interest is machine learning applied to malware detection. My final-year project builds an integrated system for detecting, remediating and forensically analysing PDF-based malware, with explainable AI so an analyst can see why a file was flagged rather than trusting a score.

Outside coursework I lead Access~Denied in the MUET Cyber Security department, where we design and run CTF and quiz competitions for other students, and I've competed in national CTFs and Pakistan's NADRA bug bounty as team lead.
